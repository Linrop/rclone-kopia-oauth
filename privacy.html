Privacy policy

Last updated: 2026-11-16

rclone-kopia is a personal backup tool used only by its owner.

Data accessed

With the owner's permission, the app accesses the owner's own Google Drive to read and write backup files. Backup contents are encrypted by Kopia before upload.

Data use and sharing

Data is used only to create and restore the owner's backups. No data is collected by the developer, sent to third parties, sold, or used for advertising. Access tokens are stored only on the owner's computer.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised via this site's GitHub repository.
